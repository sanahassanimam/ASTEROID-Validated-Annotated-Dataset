Notes:
- Atlas: Schaefer et al., 2018; 200 cortical ROIs organized in 7 networks (Yeo).
- Time series: voxel-averaged per ROI; Pearson correlations computed; Fisher r-to-z transform applied.
- Negative handling: negative z excluded; diagonal and negative values set to zero (positive weighted networks).
- Sparsity: supplementary thresholding using FDR-adjusted p < .01 for significant edges.
- Network definition: multilayer modularity with γ = 1, ω = 1; GenLouvain (MATLAB) with 'moverandw' option; averaged across 100 optimizations.
- Graph measures: flexibility, promiscuity, cohesion strength, disjointedness, recruitment; implemented with Network Community Toolbox.
- Result aggregation: 50 null models per subject; 100 optimizations per null; comparisons using Welch's two-sample t-test in R (v3.5.2).
